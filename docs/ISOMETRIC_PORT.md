Изометрическая версия находится в `slime-isometric/`. Источник — [Mahgn/slime_game](https://github.com/Mahgn/slime_game), commit `d2ee6e7022dfcb6ed0aa028f6ed945f6cca63025`. Бой в реальном времени сохранён по ответу пользователя. Наследник `SlimeIsometricController` подключён в общей сцене игрока, поэтому применяется к существующим маршрутам R01–R07, первому этажу R01–R09 и лаборатории. Базовый `scripts/player/slime_controller.gd` не изменён: SHA256 обеих копий `09fbaa76171c6a2a7f837585db43c3f3ebb1514996ee78bbfb6d184596a06a58`. Исходные HP, урон, сроки атак, поглощение, способности, слот после ядра, ловушки, босс, модели и коллизии сохранены.

Камера ортографическая: мировой yaw 45°, смещение `(12,13.9,12)`, плавное следование и немедленное сопровождение переходов >8 м. WASD соответствует направлениям экрана; курсор задаёт направление хлыста и навыков; колесо меняет размер 9–22. Видимая модель поворачивается к прицелу, физический корень не вращается за мышью.

`IsometricPresentation` скрывает заслоняющие сетки и верхние площадки, защищая обзор слайма и ближайших врагов текущей высоты. Верхние актёры скрываются вместе с площадкой и исключаются из выбора курсором; при смене высоты их видимость восстанавливается. Коллизии, ИИ и проверка стен игровыми атаками остаются активными. Визуальный срез — только способ показа существующей геометрии.

Из наших наработок взяты собственные `tomb-pillar.glb`, `oil-barrel.glb`, тёмный пергамент, бронза, тёплое освещение и Cormorant Garamond. Исходник геометрии — родительский `blender/build_vault.py` / `blender/ash-vault.blend`, экспорт — `godot/assets/`. Эти props декоративные, в отдельные сцены добавляются без новых игровых коллизий. Шрифт сопровождается исходной SIL OFL 1.1 в `assets/ash-vault/FONT-LICENSE.txt`; ресурсы занесены в `ASSET_MANIFEST.csv`. Внешние ассеты Lootdeck не копировались. Новая генерация/скачивание ассетов не выполнялись.

## Запуск

Из родительской папки: `npm run game:slime` или двойной клик `Запустить изометрию.command`. Редактор: `npm run editor:slime`. Можно открыть `project.godot` напрямую в Godot и нажать F5. `GODOT_BIN` задаёт другой бинарник для Node launcher.

В меню доступны основной маршрут, «Первый этаж · девять залов» и лаборатория внешности. Отдельный **Platformer Course / «Тест платформер»** запускается через `npm run game:slime:platform` (сцена `scenes/art_review/slime_platform_course.tscn`). По уточнению пользователя выполнен его прямой нативный запуск на 05.10.2026; Godot сообщил Compatibility / Apple M4 Max, ошибок скрипта при запуске не было. Полное прохождение этой сцены отдельно не проверено.

Сохранения/настройки изолированы через custom user-dir `slime_ascent_isometric`; они не затрагивают исходную игру. На macOS: `~/Library/Application Support/Godot/app_userdata/slime_ascent_isometric`.

| Управление | Действие |
|---|---|
| WASD | Движение относительно экрана |
| Мышь | Прицел |
| ЛКМ | Хлыст |
| E / удержание E | Взаимодействие / поглощение источника |
| ПКМ / Q | Навык первого / второго слота |
| Пробел / удержание | Прыжок / заряженный прыжок |

| Escape | Пауза / закрытие коллекции |
| Колесо мыши | Масштаб камеры |

Отдельно проверены скрытие потолка/верхнего врага с сохранением их коллизий, игнорирование скрытого врага курсором и возврат видимости на текущем этаже. Все игровые сцены загружаются с общим изометрическим игроком и правильной камерой после телепорта.

Интеграция первого этажа проверяет меню, ограниченность активных встреч, запрет коллекции в угрозе, focus-паузу через уведомление, десять перезапусков, очистку текущего боя, мастерскую и отсутствие изменения снимка основного демо. Его route использует игровые действия, а не прямой урон. Campaign-тесты стартуют с R04: Росток, смешанный зал, пресс, прыжок, Страж, перенос двух слотов и завершение. ИИ врагов в воспроизводимых маршрутах остановлен; это проверка исполнения действий и прогресса, а не сложности живого боя. Campaign-тест сохраняет и восстанавливает существующий checkpoint файл изометрической копии.

## Ограничения и открытые проверки

- Полное ручное прохождение изометрической версии пользователем: NOT_RUN. Автоматические маршруты не подменяют личную оценку боя/прыжков/ориентации.
- Настройки fullscreen и остановка ambience имеют BLOCKED в headless: нет физического окна/аудиоплеера. Нативный рендер работает, но аппаратное переключение fullscreen, звук на слух и реальный Alt-Tab отдельно NOT_RUN.
- Новый экспорт для Windows/macOS/Web: NOT_RUN. Старые упоминания сборок в исторических docs не являются сборкой этого переноса.
- При завершении route/campaign harness Godot сообщает `ObjectDB instances leaked` и `2 resources still in use at exit`, несмотря на exit 0. Эти сообщения сохранены в журналах и не скрываются. Отсутствие ошибок gameplay GDScript подтверждено; полная чистота teardown не заявляется.
- Предупреждение импорта о втором `project.godot` в `slime_lab` ожидаемо: сохранённая исходная лаборатория автоматически исключена из импорта.
- Многоэтажная карта сохраняет исходный blockout. Это перенос камеры/управления/подачи, не завершённый level art.

# Материалы коллеги

Оригинальные дизайн-документы, раскадровки и интерактивная карта перенесены из `slime_lab` без редакторского изменения. Это предложения коллеги, а не новое утверждённое ТЗ. Игровая интеграция описана в §20 `START_DEVELOPMENT.md` и `docs/SLIME_LAB_INTEGRATION.md`.

В исходных документах второй слот открывается после Панцирника. В объединённой версии он открывается только через ядро R04. Утверждения о соседнем проекте, старом commit, MCP, длительности и старых проверках относятся к версии коллеги. Собственные текущие проверки хранятся в `output/integration_slime_lab/`.

Происхождение/условия раскадровок не предоставлены: REVIEW_REQUIRED. В игре они не используются.

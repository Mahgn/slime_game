# Ассеты первого этажа

Кладите исходные изображения, звук и 3D-модели в эту папку или её подпапки. Поддерживаемые форматы для проверки импорта: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.glb`, `.gltf`, `.obj`, `.wav`, `.ogg`, `.mp3`.

`start.command` запускает Godot `--import`, затем проверяет загрузку каждого поддерживаемого файла через `ResourceLoader`. Если какой-то файл не импортируется, запуск останавливается с сообщением об ошибке. Новые файлы не добавляются на уровень автоматически: после проверки их нужно разместить в `scripts/first_floor_game.gd` или отдельной сцене.

`marker.svg` и `sample_crate.gltf` — наши временные проверочные ассеты. `slime_hero_v5.res` — локальная копия `../slime_game/assets/models/slime_hero_v5.res` из коммита `e61ccf4` для персонажа на первом этаже. Она не требует файлов соседнего проекта при запуске уровня. SHA-256 копии: `35fbd4bf96c05fe7f97d71ca602bf5a779e7131617d2845d18627eee95ab0c8d`. Файлы `.import` рядом с исходниками содержат настройки Godot; папка `.godot/` содержит пересоздаваемый кэш.

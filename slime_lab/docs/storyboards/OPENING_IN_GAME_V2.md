# Начало игры: раскадровка для постановки в Godot

**Статус:** рабочая замена постановки первых секунд, 24.09.2026. [Первый комикс](opening_comic_v1.png) показывает настроение и эмоцию; эта версия задаёт кадры, которые можно получить из одной игровой сцены.

## Одна локация, одна камера

Игрок начинает в нижней чаше шахты. Поверхность существует только как маленький проём высоко над ним. В кадре нет отдельного наружного уровня, путешествия стада и длинного падения. Через несколько секунд игрок уже управляет Слизи и сам выбирает боковой путь наверх.

| Время | Кадр из игры | Как собрать |
| --- | --- | --- |
| **0:00–0:01** | Камера уже стоит у нижней площадки. Сверху короткий свист, Слизи плюхается в мелкую лужу и на мгновение расплющивается. | Поставить персонажа чуть над полом, дать ему упасть на 1–2 м. Сжать только визуальный меш на 0,3–0,5 с; коллайдер оставить прежним. Плоское пятно воды, несколько частиц и звук заменяют симуляцию жидкости. |
| **0:01–0:03** | Слизи собирается обратно в куб. Камера показывает маленький освещённый проём наверху; у края на секунду видны три силуэта стада и слышны далёкие писки. | Три простых силуэта или копии меша без анимации на дальнем плане, один источник света в проёме, короткий звук. Игрок находится всё в той же комнате. |
| **0:03–0:05** | Камера мягко опускается за Слизи. Прямо над ним гладкая высокая стена, слева — первый широкий уступ, за ним следующий. Слизи поворачивает глаза к уступу. | Поворот той же `Camera3D`, без склейки сцен. Контрастный свет и композиция показывают первую достижимую цель. |
| **с 0:05** | Полный контроль. Игрок идёт и пробует первый обычный прыжок. Если задержится, игра ждёт; событие дальше не запускается по таймеру. | Снять блок ввода. Первый уступ сделать широким, а падение возвращать на стартовую площадку за секунды. |

## Минимальный набор для первой проверки

- Существующая модель Слизи v5 и её визуальное сжатие при приземлении. В текущей лаборатории уже есть модель, `CharacterBody3D`, движение, прыжок и небольшой импульс приземления.
- Одна новая шахта из нижней чаши, потолочного проёма и двух широких уступов с коллизией. Текущая сцена лаборатории пока представляет собой квадратную тестовую комнату; её геометрия не является уровнем.
- Один мягкий свет сверху, лужа без физики воды, два коротких звука и три далёких силуэта. Для проверки маршрута силуэты могут быть простыми формами; читаемость финального арта оценивается отдельно.
- Небольшое состояние камеры `intro`, затем обычное слежение. Текущий скрипт камеры каждый кадр следует за героем, поэтому при реализации вступительный поворот нужно явно отделить от обычного режима.

**Критерий первой игровой пробы:** игрок получает управление примерно через 5 секунд, сразу видит недоступный верх и достижимый боковой уступ, без подсказки пробует двигаться к нему. Если кадр не объясняет маршрут, меняется геометрия и свет, а не добавляется длинный текст.

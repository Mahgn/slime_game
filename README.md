# Слайм: путь наверх — прототип `slime_ascent`

Основной репозиторий исходников: [Mahgn/slime_game](https://github.com/Mahgn/slime_game). Локальные сборки, журналы и кадры из `output/` в Git не входят.

Документы и проект Godot подготовлены 23.09.2026 на основе исходного концепта `1244.docx`. Реализованы короткий цикл S2, образец зала S3 и отдельное испытание навыков S4. Начат S5: игра открывается безопасным входом R01 с подъемом к свету, затем переводит в прежний R02. После второго Плевуна кнопка ведет в испытание S4. Камера по отзыву пользователя немного поднята и отодвинута; поворот мышью работает в оконном тесте. Остальные комнаты S5, сохранение, босс и завершение еще не готовы. Подробности — в `docs/PROJECT_STATUS.md` и `output/S5/VALIDATION_REPORT.md`.

## Запуск проверенной сборки Windows

В этой рабочей папке создана debug-сборка для Windows x86_64. Запустить её можно из PowerShell:

```powershell
Set-Location 'D:\Projects\slime_codex_start_v1'
& '.\output\S5\build\slime_ascent.exe'
```

Файлы `slime_ascent.exe` и `slime_ascent.pck` должны лежать рядом. Сборка S5 экспортирована и запущена в видимом окне на указанной ниже тестовой машине; ручное прохождение человеком пока не подтверждено. `output/` не входит в исходники, поэтому эта локальная сборка не появится при новом получении проекта.

## Запуск из Godot

На проверенной машине установлен Godot `4.7.2.stable.steam.ed1daf0bf` для Windows. Главная сцена задана в `project.godot` как `res://scenes/r01_entrance.tscn`, renderer — Compatibility. В текущей рабочей папке есть локальная копия Godot, поэтому из PowerShell можно запустить исходный проект:

```powershell
Set-Location 'D:\Projects\slime_codex_start_v1'
& '.\output\S0\runtime\godot.exe' --path .
```

Локальная копия в `output/` не входит в исходники. Если её нет, укажите путь к своему Godot 4.7.2 stable либо откройте `project.godot` в этой версии редактора. На этой машине исходный файл редактора находится в `D:\Program Files (x86)\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe`. Для чистого импорта в изолированной среде использовалась копия в `output/S0/runtime/` и отдельные каталоги `APPDATA`/`LOCALAPPDATA`; детали и журналы — в `output/S0/checks.txt`.

Для прямой проверки испытания S4 из исходников: `& '.\output\S0\runtime\godot.exe' --path . --scene res://scenes/s4_trial.tscn`. Экспортная сборка начинает с S2 и переходит в S4 через кнопку после второго боя.

## Управление

| Действие | Ввод |
|---|---|
| Движение | WASD, физические клавиши |
| Камера | Мышь при захваченном курсоре |
| Прыжок | Пробел |
| Хлыст | ЛКМ |
| Поглощение источника после первой победы | Удерживать E рядом с ним |
| Первый / второй навык | ПКМ / Q |
| Коллекция вне боя в испытании S4 | Tab; выбрать слот, затем навык |
| Пауза / продолжить | Escape |
| Повтор после поражения или победы | R или кнопка «Повторить» |

От завала идите по пандусу к свету на верхней площадке: переход в R02 происходит автоматически. Дайте Плевуну показать выстрел, затем победите его хлыстом. Подойдите к остатку и удерживайте E; после появления награды пройдите к золотой отметке и попробуйте плевок против второго Плевуна. После победы откройте испытание S4 кнопкой на экране. Победите Панцирника и поглотите панцирь, удерживайте E у золотого ядра для второго слота, затем победите Каменного ростка и поглотите шипы. В безопасное окно нажмите Tab и выберите два навыка перед смешанным боем. Коллекция закрывает бой на паузу; Escape сначала закрывает коллекцию. Дальнейшие комнаты, босс и сохранения относятся к продолжению S5.
